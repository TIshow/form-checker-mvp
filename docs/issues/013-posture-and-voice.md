# Issue 013: 姿勢 × 響き（オペラの結果を音声で測る）

Status: Open
作成: 2026-09-20

## なぜ今これを書くか

オペラ歌手からの相談は「歌っているときの姿勢と響きに関係があるようで、
それを直したい」だった。姿勢だけを測っても**相談には答えられない**。
答えるには「響き」を測って、姿勢と結びつける必要がある。

3競技の中でオペラだけは、この「結果」が**同じ動画の音声トラックに最初から
入っている**（[011 §4](011-commercial-architecture.md)）。テニスで 42本測っても
結果データが無くて何も言えなかった（[010](010-outcome-measurement.md)）のと
対照的で、**フォーム→結果の因果を最初に示せる競技**になりうる。

姿勢側は `domains/opera_posture.py` で実映像を通した（2026-09-20）。
残っているのは音声側と、両者を結ぶ設計。

## 何を測るか（音声側）

歌唱の「響き」として文献で扱われる量。**すべて出典を本文で確認してから閾値を
置く**（[domains/base.py](../../domains/base.py) の TIER 規律はここにも適用する）。

| 量 | 何の代用か | 計算 |
|---|---|---|
| 音圧（RMS / SPL相当） | 声量 | 短時間 RMS。絶対 dB は録音条件に依存するので**同一録音内の相対値**のみ |
| スペクトル傾斜 | 声の明るさ・張り | 低域と高域のエネルギー比 |
| シンガーズフォルマント比 | 「通る声」 | 2.8〜3.4 kHz 帯のエネルギー / 全体。**帯域は出典で確認** |
| F0（基本周波数）とその安定性 | 音程の保持 | 自己相関で推定。持続音区間の F0 の標準偏差 |
| ビブラート | 周期と深さ | F0 の 4〜8 Hz 成分 |

全部 numpy で書ける。外部の音声ライブラリは要らない
（ffmpeg で wav に落とすところだけ `imageio_ffmpeg` の同梱バイナリを使う）。

## 姿勢とどう結ぶか

**同じフレーズを、姿勢を変えて何度も歌ってもらう。** これが要点。

- 1本の動画の中で姿勢と音声の相関を取っても、**フレーズの違い**（音域・母音・
  強弱）が交絡して何も言えない
- 同一歌手・同一フレーズ・姿勢だけ変える、なら**被験者内の反復測定**になり、
  テニスで効かなかった被験者間のばらつきを回避できる
- 本人の「今のは響いた／響かなかった」という主観評価も同時に記録する。
  **正解データが本人から取れる**のがこの競技の強み

時間軸は動画と音声で共通（同じファイル）。姿勢の指標を区間ごとに出し、
同じ区間の音声量と並べる。

## 技術的な段取り

1. `core/audio.py` — 動画から wav を抽出し、上の量を時系列で返す（純 numpy）
2. `domains/opera_posture.py` — `measure` に音声量を足す。姿勢と同じ区間で集計
3. `web/clip.html` — オペラのときだけ音圧の曲線をスクラブの下に描く。
   デモで「ここで姿勢がこう、ここで声がこう」と指せるようにする
4. 反復測定のプロトコルを1枚にまとめ、歌手に撮ってもらう
5. 判定は入れない。**姿勢と音声の対応表を出すところまで**

## 確かめてから進むこと

- **SMPL 24関節で足りるか。** 効くとされるのは頭頸部・胸郭・顎。24関節には
  無い。MHR の 70点には耳・鼻がある（頭の向きは取れる）が、顎・喉頭は無い。
  ここは実機で「本人が姿勢を変えた自覚があるとき、数値が動くか」で決める
- **ばらつき系の指標にジッタが乗る。** 単一画像モデルでは揺れ・SD が
  GVHMR の 1.5〜3倍出た（2026-09-20）。同一手法内の比較に限る
- **録音条件。** マイクの距離・会場・機材が変わると絶対値は比べられない。
  同一セッション内の相対比較に限る
